# Notes for Claude

## TAD meetings: standing instruction
Whenever Nakita, Colin or Pate share a recorded or transcribed **TAD (The Art Department) meeting**, summarise it and file it in the shared Google Drive folder **TAD Fiji HQ**. Do this without being asked each time.

- TAD Fiji HQ: https://drive.google.com/drive/folders/1-B2PotVC7y3obaH-IWUL45oiSntomZ9k
- The full process lives in Drive at **00 · Start Here › Meeting Process · Record → Summarise → File**. Read it and follow it.
- In short:
  1. Create `01 · Meetings › YYYY-MM-DD · Topic`.
  2. Add four Google Docs: Summary, Next Steps, Full Meeting Notes, Transcript.
  3. Add a row to the **Meeting Log**.
  4. Add the actions to the **TAD Master Action Tracker** (`02 · Action Tracker`).
  5. Update the Projects, Partners, Talent and Contacts sheets where relevant.
  6. Put confidential items in `11 · Special Projects (Confidential)`.
  7. Draft (don't send) a recap email to the TAD addresses.
- Never put meeting content in this repository. It is public.
- Upload docs to Drive as `text/markdown`, and avoid emoji (they get garbled on conversion).
